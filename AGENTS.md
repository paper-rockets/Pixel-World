# Project Agent Instructions

## Persistence

When the user reports an issue or a requested fix remains unresolved, continue diagnosing, implementing, testing, and correcting it until the issue is actually resolved and verified.

Do not stop at a status report, diagnosis, plan, partial implementation, first pass, or failed test. Do not pause merely to ask whether to continue. Pause only when the user explicitly asks to pause or stop, the requested outcome is complete, a safety or permission boundary requires user input, or progress is genuinely blocked after exhausting safe in-scope options.
